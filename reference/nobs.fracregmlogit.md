# Extract the Number of Observations for fracregmlogit

Extracts the number of observations used to estimate a `fracregmlogit`
model.

## Usage

``` r
# S3 method for class 'fracregmlogit'
nobs(object, ...)
```

## Arguments

- object:

  A fitted model object of class `fracregmlogit`.

- ...:

  Further arguments passed to or from other methods.

## Value

An integer denoting the number of observations.
