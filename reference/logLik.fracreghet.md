# Extract Log-Likelihood for fracreghet

Extracts the log-pseudolikelihood or log-likelihood from a fitted
`fracreghet` model.

## Usage

``` r
# S3 method for class 'fracreghet'
logLik(object, ...)
```

## Arguments

- object:

  A fitted model object of class `fracreghet`.

- ...:

  Further arguments passed to or from other methods.

## Value

An object of class `logLik`.
