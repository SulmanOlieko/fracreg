# Extract Log-Likelihood for fracregpd

Extracts the log-pseudolikelihood or log-likelihood from a fitted
`fracregpd` model.

## Usage

``` r
# S3 method for class 'fracregpd'
logLik(object, ...)
```

## Arguments

- object:

  A fitted model object of class `fracregpd`.

- ...:

  Further arguments passed to or from other methods.

## Value

An object of class `logLik`.
