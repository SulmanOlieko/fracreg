# Extract Log-Likelihood for fracreg

Extracts the log-pseudolikelihood or log-likelihood from a fitted
`fracreg` model.

## Usage

``` r
# S3 method for class 'fracreg'
logLik(object, ...)
```

## Arguments

- object:

  A fitted model object of class `fracreg`.

- ...:

  Further arguments passed to or from other methods.

## Value

An object of class `logLik`.
