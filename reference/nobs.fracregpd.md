# Extract the Number of Observations for fracregpd

Extracts the number of observations used to estimate a `fracregpd`
model.

## Usage

``` r
# S3 method for class 'fracregpd'
nobs(object, ...)
```

## Arguments

- object:

  A fitted model object of class `fracregpd`.

- ...:

  Further arguments passed to or from other methods.

## Value

An integer denoting the number of observations.
