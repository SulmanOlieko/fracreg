# Extract the Number of Observations for fracreghet

Extracts the number of observations used to estimate a `fracreghet`
model.

## Usage

``` r
# S3 method for class 'fracreghet'
nobs(object, ...)
```

## Arguments

- object:

  A fitted model object of class `fracreghet`.

- ...:

  Further arguments passed to or from other methods.

## Value

An integer denoting the number of observations.
