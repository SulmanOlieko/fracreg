# Extract the Number of Observations for fracregridge

Extracts the number of observations used to estimate a `fracregridge`
model.

## Usage

``` r
# S3 method for class 'fracregridge'
nobs(object, ...)
```

## Arguments

- object:

  A fitted model object of class `fracregridge`.

- ...:

  Further arguments passed to or from other methods.

## Value

An integer denoting the number of observations.
