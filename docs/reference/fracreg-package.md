# Fractional Regression Models

Provides tools for the estimation and specification analysis of both
one-part and two-part fractional regression models. It supports various
link functions, allows for the calculation of average and conditional
partial effects, and provides several specification tests such as RESET,
P test, and GGOFF tests.
